To recreate the generated part of bluebridge-client manpage use a command like:
  help2man -N --output=bluebridge-client.1 --name='BlueBridge Keyboard/Mouse Client' /path/to/bluebridge-client

And for bluebridge-server:
  help2man -N --output=bluebridge-server.1 --name='BlueBridge Keyboard/Mouse Server' /path/to/bluebridge-server

After that manually fixup:
 * replace your home directory with $HOME in bluebridge-server.1
 * revert formatting of FILES and COPYRIGHT sections to match formatting of existing version.
 * add note referencing this file for instructions to the first line.
